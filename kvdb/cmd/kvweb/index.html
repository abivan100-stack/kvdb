kvdb

Every write goes to the end of the file.

kvdb is a small database written from scratch in Go. This page talks to its real file on your computer. Save, overwrite and delete keys and watch the file grow. Old records pile up until you compact the file.

The file, record by record

  • Current value of a key
  • Out of date (replaced or deleted later)
  • Delete marker

The file is empty. Save a key below to write its first record.

Select a block to inspect that record. Use the arrow keys when the strip has focus.
